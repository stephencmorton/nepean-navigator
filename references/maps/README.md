# School-layout references

These images were supplied by the project owner as early references for the school layout. The app and the map tools no longer use them; the map now comes entirely from the master drawing, [tools/floorplans.svg](../../tools/floorplans.svg). They are kept for cross-checking when that drawing is revised.

- `nepean_top_view.jpg`: numbered building footprints.
- `nepean_map_v10.jpg`: isometric view from the same source, useful for relative building placement.
- `nepean_buildings.png`: alternate top-view diagram with the project owner's best memory of hallway alignments.

These are informal sketches. They do not establish exact room positions, measured corridor paths, floor-specific connections, stairwell locations, or compass orientation; graph connectivity is defined only by `data.js`.

These files are development references and are not deployed.
