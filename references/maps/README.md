# School-layout references

These images were supplied by the project owner for the building-route overview.

- `nepean_top_view.jpg`: numbered building footprints, used to trace the approximate SVG outlines in `data.js`.
- `nepean_map_v10.jpg`: isometric view from the same source, used to cross-check relative building placement.
- `nepean_buildings.png`: alternate top-view diagram with the project owner’s best memory of hallway alignments. It places Main’s connections near its two ends and guides the approximate dotted corridors and route overlays. This supplied file is a raster PNG.

The remembered hallway sketch is provisional. It does not establish exact room positions, measured corridor paths, floor-specific connections, stairwell locations, or compass orientation. Graph connectivity remains defined by the existing school data. Gray dots show approximate hallways; purple routes use those alignments and join at Main’s end junctions.

These files are development references and are excluded from the production asset list. The rendered map is SVG generated from code and works offline without loading these originals.
